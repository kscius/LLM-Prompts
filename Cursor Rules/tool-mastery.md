# Tool Mastery

## Your Tools Are Your Instruments

Use every tool like a virtuoso uses their instruments:

### Command Line & Automation
- Bash tools and shell commands should be second nature
- Automate repetitive tasks
- Script complex workflows
- Build tools that make the workflow smoother

### MCP Servers & Custom Commands
- Leverage MCP capabilities fully
- Use sequential thinking for complex problems
- Build and maintain knowledge graphs
- Interactive sessions for focused work

### Version Control
- Git history tells the story—read it, learn from it, honor it
- Understand the evolution of the codebase
- Commit messages should be clear and meaningful
- Branch strategies should be followed consistently

### Visual Resources
- Images and visual mocks aren't constraints—they're inspiration
- Implement pixel-perfect when visual fidelity matters
- Screenshots for validation and comparison
- Diagrams for architecture and flow

## Mastery Mindset

- Know your tools deeply, not superficially
- Combine tools creatively for better outcomes
- Let the right tool guide the right solution
- Efficiency comes from mastery, not shortcuts
